قاعدة البيانات

جيت هب مش قاعدة بيانات. هنربط ZIVV بـ Supabase (مجاني) عشان المنشورات واللايك والشات تشتغل بين الناس.

  1. افتح supabase.com وسجّل حساب
  2. New project — اختار أقرب منطقة وباسورد للقاعدة
  3. SQL Editor → New query → الصق محتوى ملف sql/zivv.sql → Run
  4. Project Settings → API → انسخ Project URL و anon public
  5. حطهم تحت واحفظ
